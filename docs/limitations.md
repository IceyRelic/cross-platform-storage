# 局限与待验证

- 公共版本未重建/重跑；原实测来自固定时间窗口，当前启动故障未完成修复。
- 单宿主Workstation控制器与两数据VM是实验隔离模型，不是生产BMC/控制器HA。
- 尚未验全部分区/双向竞态/证书失效/宿主重启/会话生命周期；历史底层通信原因未完整归因。
- NFS旧句柄/锁不能概括透明恢复，显式示例只适用于普通文件且协作锁一致的客户端。
- 三共享7版不扩为LUN7版；LUN自然捕获/轮换、历史发布写中崩溃仍有缺口。
- 正式LUN样本为空文件系统目录，不把容量模型当真实业务数据一致性。
- 512MiB/inode准入不替代根文件系统/宿主薄置备硬空间约束。
- 较小缓存工作集/固定队列，未得到可归因性能提升百分比/99.9%/最大吞吐。
- 41规则数量与10目标快照不代表每条实发/用户收到，更没有平均MTTD/MTTI。
- Corosync旧模板secauth off只代表原隔离实验配置，不宣称生产集群通信安全。
- Python2.7/旧系统语法保持，不假称已完成现代化迁移。
- 标准DRBD/OCF vendor实现不随包；基础组件来源/许可、私有参数和完整空环境重建需自行核对。
