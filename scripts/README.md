# 脚本作用与边界

diagnostics/storage-status.sh只读，但必须在正确存储节点，不在同地址K8s节点执行。

backup/脚本会读/写/发布备份状态和历史；LUN helper会操作暂存与上传，需私有配置/精确设备身份。systemd安装路径必须与脚本硬编码依赖一致。不要直接一键跑所有文件。

fencing/的broker/agent可执行指定节点off；只在充分核对参数的隔离实验环境操作。UUID/MAC/路径/TLS/nonce/期限/原生状态/持久未决检查不能去掉；公开参数未填应拒绝。缺少实际参数、不同SHA或-O均应失败。

storage/nfs_safe_reopen.py是普通文件夹具库，保留私有根/挂载/身份/锁守卫；没有后台透明恢复全部旧句柄的承诺。

历史注释副本带“阅读副本”说明，原SHA留本地来源台账；这里做公开参数变化后的新字节，未以原测试假称公开版已验。已有self-check/model入口只是源码保留，本次不执行。
